# ALU Web Development - HTML Basics

This repository contains introductory projects for the Web Development module at African Leadership University (ALU).

## Project Overview: `html_basic`

The `html_basic` directory introduces fundamental HTML concepts, core semantic tags, and valid HTML5 page structuring compliant with W3C standards.

### Files and Tasks

- **`base_index.html`**: A basic, minimal, and valid HTML5 boilerplate containing standard `<!DOCTYPE html>`, `<html>`, `<head>`, `<meta charset="UTF-8">`, `<title>`, and `<body>` tags.
- **`index.html`**: A structured webpage containing semantic headings (`<h1>`, `<h2>`, `<h3>`), paragraphs (`<p>`), navigation links (`<a>`), and a clickable image (`<img>` nested inside an `<a>`). Follows a three-tier layout (`<header>`, `<main>`, `<footer>`) with `<article>` and `<aside>` sections.
- **`tweets.html`**: A webpage featuring an embedded tweet, consistent page layout (`<header>`, `<main>`, `<footer>`), navigation links back to the homepage (`index.html`), and a sidebar placeholder (`<aside>`).
